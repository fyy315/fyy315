<h1>人工智能商标交易撮合平台 - 测试/部署/运维</h1><h2>1. 测试策略</h2><h3>1.1 单元测试</h3><ul><li><strong>工具</strong>：Jest</li><li><strong>覆盖率要求</strong>：核心逻辑（NL2SQL校验、侵权相似度算法、订单状态机）覆盖率 &gt; 90%。</li><li><strong>Mock策略</strong>：对外部API（启信网、智慧芽、支付宝、SCNET）进行Mock，避免测试产生真实费用。</li></ul><p> </p><h3>1.2 集成与API测试</h3><ul><li><strong>工具</strong>：Supertest</li><li><strong>核心场景</strong>：<ul><li>验证JWT鉴权失败返回401/403。</li><li>验证订单完整生命周期（创建-&gt;支付-&gt;过户-&gt;完成）。</li><li>验证双重查询降级策略（启信网报错时自动切换智慧芽）。</li></ul></li></ul><p> </p><h3>1.3 端到端测试 (E2E)</h3><ul><li><strong>工具</strong>：Cypress / Playwright</li><li><strong>核心链路</strong>：<ul><li>用户注册 -&gt; 搜索商标 -&gt; 加入购物车 -&gt; 结算 -&gt; 模拟支付 -&gt; 验证订单。</li><li>权利人上架 -&gt; 设置英式拍卖 -&gt; 需求人出价 -&gt; 权利人结束竞价。</li></ul></li></ul><p> </p><h3>1.4 性能与并发测试</h3><ul><li><strong>工具</strong>：k6 / Artillery</li><li><strong>重点</strong>：对出价接口进行并发测试，验证Redis分布式锁的有效性，确保绝对不超卖。</li></ul><p> </p><h2>2. 部署架构与CI/CD</h2><h3>2.1 容器化</h3><ul><li>前后端均编写 Dockerfile，使用多阶段构建减小镜像体积。</li><li>编排 docker-compose.yml 用于本地开发环境一键启动。</li></ul><p> </p><h3>2.2 生产环境部署</h3><ul><li><strong>前端</strong>：部署至 <strong>Vercel</strong>，自动适配全球CDN，支持Next.js SSR边缘计算。</li><li><strong>后端</strong>：部署至 <strong>阿里云 ECS / Railway</strong>，采用 Nginx 反向代理 + PM2 集群模式管理Node进程。</li><li><strong>数据库</strong>：<strong>阿里云 RDS MySQL 8.0</strong>，开启自动备份与读写分离。</li><li><strong>缓存</strong>：<strong>阿里云 Redis</strong>，用于分布式锁和热点数据缓存。</li></ul><p> </p><h3>2.3 CI/CD 流水线</h3><ul><li><strong>工具</strong>：GitHub Actions</li><li><strong>流程</strong>：</li></ul><p>1. <strong>CI</strong>：Push到PR触发 Lint检查 -&gt; 单元测试 -&gt; 构建Docker镜像。</p><p>2. <strong>CD</strong>：合并到 develop 自动部署Staging；合并到 main 自动部署Production。</p><p>3. <strong>数据库迁移</strong>：部署流水线中自动执行 npm run migrate。</p><p> </p><h2>3. 运维与监控体系</h2><h3>3.1 日志管理</h3><ul><li><strong>方案</strong>：后端使用 Winston / Pino 输出JSON结构化日志。</li><li><strong>采集</strong>：使用 Filebeat 采集，发送至 ELK (Elasticsearch, Logstash, Kibana) 进行集中查询。</li><li><strong>关键日志</strong>：API响应时间、第三方API调用降级记录、NL2SQL生成记录与原始问题、支付回调结果。</li></ul><p> </p><h3>3.2 监控与告警</h3><ul><li><strong>基础监控</strong>：Prometheus + Grafana 监控服务器CPU、内存、DB连接池、Redis内存。</li><li><strong>业务监控</strong>：订单转化率、支付成功率、AI接口调用延迟。</li><li><strong>告警</strong>：集成钉钉/企业微信机器人，对于服务宕机、数据库连接耗尽、AI接口持续报错触发立即告警。</li></ul><p> </p><h3>3.3 数据备份与灾备</h3><ul><li><strong>MySQL</strong>：开启 RDS 每日自动物理备份与 Binlog 实时备份，保留周期30天。</li><li><strong>文件存储</strong>：用户上传的证据文件存储于阿里云 OSS，开启跨区域冗余。</li><li><strong>灾备</strong>：生产环境数据库建立跨可用区只读从库，主库宕机时快速切换。</li></ul>
